## Answer (≤5 lines)
The extractor keeps all LODs (3 tfrag, 4 tie, none for shrub), but the PC renderer draws a
single global LOD (0 by default; the PS2 distance LOD path is disabled): no distance switching
or fade. Culling is frustum + per-level BSP vis bits from one camera. tfrag LOD copies carry
copies of the same palette; tie palettes are per proto and shared by all instances and LODs.

## Implications for the design
- Unbake per palette entry. tfrag LODs inherit it for free. tie entries can be shared across
  instances with different normals, so the fit must pool samples per entry or split entries.
- This refines `facts/mood.md` claim 5: instances own index lists, not palette slices.
- SSAO: no LOD pops by default; geometry is stable across distance.
- Stereo: one frustum + one vis decision per level per frame. Use a union frustum or a second
  cull pass; LOD needs no per-eye handling while it stays global.
- Far scenery is ordinary level geometry (inferred); no special backdrop to relight.
